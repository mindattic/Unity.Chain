- **U.CHN-US-F8 ✅** As a player, my volumes, mutes and display name persist in my profile, so that settings follow the shared MindAttic profile model
- **U.CHN-US-F9 ✅** As a player, the HUD and menus are built with UI Toolkit (or the shared MindAttic components) instead of IMGUI, so that the UI follows the modern Unity standard
